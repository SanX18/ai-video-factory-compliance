# Política de privacidad

Este proyecto ("AI Video Factory") es una herramienta personal de automatización
que usa la API de TikTok únicamente para publicar vídeos en la cuenta propia del
desarrollador. No recopila, almacena ni comparte datos personales de terceros.

Los únicos datos gestionados son las credenciales de autenticación (tokens de
acceso) necesarias para publicar en la propia cuenta del desarrollador, que se
guardan de forma privada como secretos cifrados en GitHub Actions y nunca se
comparten con terceros.
